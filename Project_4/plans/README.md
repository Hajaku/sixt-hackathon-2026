# plans/

Plan CSVs in the scorer's format (`fleetkit.write_plan`). Each solved plan has a `.json` next to it with the solver, status, time, gap and model objective. Every plan is logged with its score in `Notes/Experiments.md`.

## Final candidates (Level 3, drivers + trucks + upgrades, exact R7 greedy)
Profits are from our scorer on 500 evaluation scenarios (seed 2026). It matches the official scorer on the public scenario.

| File | Objective | Same as | Profit |
|---|---|---|---:|
| `final_point.csv` | buckets at the point forecast E[D] | `cmp_L3_point_greedy` | 4,108,409 |
| `final_saa_20.csv` | classic SAA, 20 scenarios | `cmp_L3_saa_up_greedy_20` | 4,098,427 |
| `final_saa.csv` | classic SAA, 10 scenarios | `cmp_L3_saa_up_greedy` | 4,095,776 |
| `final_curves.csv` | expected-revenue curves (M2), 500 scenarios | `cmp_L3_curves_up_more_greedy` | 4,060,965 |

Reproduce: `.venv/bin/python scripts/make_final.py --objective point|saa`. It writes `plans/final.csv` and `plans/final.json`.

## References
- `do_nothing.csv`: an empty plan (3.02 M).
- `baseline.csv`: fleetkit's baseline rule (3.12 M), not in git, regenerated by `fleetkit.baseline_plan`.

## Experiments: `cmp_L<level>_<variant>[_suffix].csv`
Written by `scripts/compare_objectives.py solve` and `scripts/run_saa_bootstrap.py solve`.
- **Variants:** `point`, `saa_up`, `curves_*` (see the scripts' docstrings).
- **Suffixes:**
  - `_greedy`: `--exact-greedy`
  - `_20`: 20 SAA scenarios
  - `_boot`: bootstrap scenarios
  - `_v2`: rerun after the spec audit
